Day 26 нельзя полностью закрыть технически без данных реального продавца и согласованных юридических текстов.

## Legal checklist

| Пункт | Что нужно | Ready | Risk |
|---|---|---|---|
| Реквизиты продавца | ИП/ООО, ИНН, ОГРН/ОГРНИП, адрес, контакты | Нет | Нельзя безопасно запускать публичную продажу |
| Оферта | Условия покупки, сроки доступа, ограничения, возвраты | Нет | Споры с клиентами |
| Политика конфиденциальности | Какие данные собираются и зачем | Нет | Нарушение ожиданий пользователей |
| Согласие на обработку данных | Текст согласия на сайте/checkout | Нет | Нет явного согласия |
| Правила возврата | Условия отмены и возврата платежа | Нет | Платежные и юридические претензии |
| Контакты поддержки | Telegram и `help@alanet.ru` | Да | Нужно поддерживать SLA |
| Retention policy | Сроки хранения логов, заказов, платежей, audit | Частично | Нужна финальная юридическая валидация |
| Data deletion request | Процедура удаления/анонимизации клиента | Частично | Нельзя удалить финансовые записи без учёта закона |

## Минимальный набор текстов для сайта

Перед публичным checkout на сайте нужны:

1. Оферта.
2. Политика конфиденциальности.
3. Согласие на обработку персональных данных.
4. Правила возврата.
5. Контакты поддержки.
6. Информация о продавце.

## Технические требования к публикации

- [ ] Сохранить версию юридического текста, принятую клиентом.
- [ ] Не включать публичный website checkout до готовности документов.

## Retention draft

| Данные | Предлагаемый срок | Комментарий |
|---|---:|---|
| Web login token | 15 минут | уже соответствует текущей модели |
| Telegram bind token | 7 дней | уже соответствует текущей модели |
| Web session | до 30 дней | зависит от политики безопасности |
| Audit log | 90 дней | дольше только при incident |
| Operational alerts | 90 дней | без секретов и subscription URLs |
| Orders/payments | по требованиям учета и налогов | подтвердить с бухгалтером/юристом |
| Subscription URLs | только пока нужна активная подписка | не отправлять в логи |
